# Domain Docs

This is a single-context repository.

Before exploring implementation, read `CONTEXT.md` at the repository root and any relevant ADRs under `docs/adr/`. If those paths do not exist, proceed silently. Create them only when the domain language or an architectural decision needs a durable record.

Use the vocabulary defined in `CONTEXT.md` in Bean titles, plans, code, and tests. If a needed concept is absent, reconsider whether the concept belongs or record the genuine vocabulary gap.

If proposed work contradicts an ADR, call out the conflict explicitly. Do not silently override the recorded design.
